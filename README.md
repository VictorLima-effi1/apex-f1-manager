# Apex F1 Manager 🏎️

Jogo de gerenciamento de Fórmula 1 desenvolvido em Godot 4.

## 🔄 Rotina de Sincronização (Git)

### 1. Antes de começar a programar:
Sempre rode o pull (cmd no aquivos) antes de abrir o editor da Godot:

git pull


### 2. Ao finalizar o trabalho do dia:
Salve tudo na Godot, feche a engine e rode no terminal:

git add .

git commit -m "Sua mensagem sobre o que foi feito"

git push
